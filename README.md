# Customer Shopping Behaviour Segmentation using K-Means Clustering

## Project Overview

This project applies unsupervised machine learning to segment customers based on their shopping behaviour. The analysis combines exploratory data analysis (EDA), feature engineering, customer profiling, and clustering techniques to identify distinct customer segments and generate business insights for targeted marketing strategies.

## Objectives

* Explore customer shopping behaviour through EDA.
* Engineer categorical features for clustering.
* Build customer segments using K-Means clustering.
* Evaluate clustering using the Elbow Method and Silhouette Score.
* Compare K-Means with DBSCAN, OPTICS, and Agglomerative Clustering.
* Profile each customer segment and provide business recommendations.

## Dataset Features

Customer ID, Gender, Item Purchased, Category, Purchase Amount, Location, Size, Color, Season, Subscription Status, Shipping Type, Discount Applied, Promo Code Used, Previous Purchases, Payment Method, Frequency of Purchases.

## Tools & Libraries

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SciPy.

## Key Results

* K-Means identified three customer segments.
* Customer segments differed mainly in subscription behaviour, discount usage, promo code usage, and gender distribution.
* DBSCAN and OPTICS produced poor clustering performance on this dataset.
* Cluster profiling revealed opportunities for personalized marketing and subscription campaigns.
